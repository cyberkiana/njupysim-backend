# NJUPTPhySim 服务器部署指南（一体化部署）

> 目标：把整套系统（前端 + 后端 + MySQL + Redis + nginx）部署到**一台独立服务器**，
> 对外只暴露 80 端口，访问 `http://服务器IP` 即是完整系统。
>
> 本 `deploy/` 目录就是全部部署材料：

| 文件 | 说明 | 去向 |
|------|------|------|
| `NJUPTPhySim-0.0.1-SNAPSHOT.jar` | 后端（含全部依赖） | `/opt/njuptphysim/` |
| `application-prod.yml` | 生产配置（**先改密码再上传**） | `/opt/njuptphysim/`（与jar同目录） |
| `dist/` | 前端静态文件 | `/data/nginx/web/dist/` |
| `nginx-server.conf` | nginx配置 | `/etc/nginx/nginx.conf` |
| `njupt_physim_dump.sql` | 数据库完整导出（19张表） | 导入服务器MySQL |

> 以下命令以 CentOS 为例，Ubuntu 的等价命令在行内标注。

---

## 一、上传部署材料

用 scp / Xftp / FinalShell 把 deploy 目录内容上传：

```bash
mkdir -p /opt/njuptphysim /data/nginx/web/dist /data/nginx/avatar
# 上传 jar 和 application-prod.yml 到 /opt/njuptphysim/
# 上传 dist/* 到 /data/nginx/web/dist/
```

## 二、安装 JDK 17

```bash
sudo yum install -y java-17-openjdk java-17-openjdk-devel      # CentOS
# Ubuntu: sudo apt install -y openjdk-17-jdk
java -version   # 确认 17.x
```

## 三、安装 MySQL 并导入数据库

```bash
sudo yum install -y mysql-server && sudo systemctl enable --now mysqld   # CentOS
# Ubuntu: sudo apt install -y mysql-server && sudo systemctl enable --now mysql

# 创建业务库和账号（把密码换成你自己的，要与 application-prod.yml 一致）
sudo mysql <<'EOF'
CREATE DATABASE IF NOT EXISTS njupt_physim DEFAULT CHARSET utf8mb4;
CREATE USER IF NOT EXISTS 'njupt'@'127.0.0.1' IDENTIFIED BY '你的MySQL密码';
CREATE USER IF NOT EXISTS 'njupt'@'localhost' IDENTIFIED BY '你的MySQL密码';
GRANT ALL PRIVILEGES ON njupt_physim.* TO 'njupt'@'127.0.0.1';
GRANT ALL PRIVILEGES ON njupt_physim.* TO 'njupt'@'localhost';
FLUSH PRIVILEGES;
EOF

# 导入数据
mysql -unjupt -p njupt_physim < /opt/njuptphysim/njupt_physim_dump.sql

# 验证
mysql -unjupt -p -e "use njupt_physim; show tables; select count(*) from users;"
```

> 安全建议：MySQL 不要对公网开放。确认 `bind-address=127.0.0.1`
> （`/etc/my.cnf` 的 `[mysqld]` 段），云服务器安全组不要放行3306。

## 四、安装 Redis

```bash
sudo yum install -y redis && sudo systemctl enable --now redisd  # CentOS（服务名可能是 redis）
# Ubuntu: sudo apt install -y redis-server && sudo systemctl enable --now redis-server

# 设置密码（要与 application-prod.yml 一致）
sudo sed -i 's/^# *requirepass .*/requirepass 你的Redis密码/' /etc/redis.conf   # CentOS路径
sudo systemctl restart redis
redis-cli -a 你的Redis密码 ping    # 返回 PONG 即正常
```

> 安全建议：Redis 同样只监听 127.0.0.1（默认即是），安全组不要放行6379。

## 五、安装 nginx 并放置配置

```bash
sudo yum install -y epel-release nginx   # CentOS；Ubuntu: sudo apt install -y nginx
# 确认 dav 模块（头像上传依赖，官方包一般都带）
nginx -V 2>&1 | tr ' ' '\n' | grep dav    # 应输出 --with-http_dav_module

sudo cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak
sudo cp /opt/njuptphysim/nginx-server.conf /etc/nginx/nginx.conf   # 或手动粘贴内容
sudo chown -R nginx:nginx /data/nginx/avatar
sudo chmod 755 /data/nginx/avatar /data/nginx/web

# SELinux（CentOS 且 Enforcing 时执行）
getenforce
sudo chcon -R -t httpd_sys_rw_content_t /data/nginx/avatar
sudo setsebool -P httpd_can_network_connect 1

sudo nginx -t && sudo systemctl enable --now nginx
```

## 六、修改并核对生产配置

编辑 `/opt/njuptphysim/application-prod.yml`，把两处 `【修改】` 的密码
（MySQL、Redis）改成你在第三、四步设置的值。

## 七、启动后端

```bash
cd /opt/njuptphysim
nohup java -jar NJUPTPhySim-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod > backend.log 2>&1 &
tail -f backend.log    # 等待出现 "Tomcat started on port 8081"
```

（可选）做成开机自启的 systemd 服务 `/etc/systemd/system/njuptphysim.service`：

```ini
[Unit]
Description=NJUPTPhySim Backend
After=network.target mysqld.service

[Service]
WorkingDirectory=/opt/njuptphysim
ExecStart=/usr/bin/java -jar NJUPTPhySim-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now njuptphysim
```

## 八、验证清单

| 检查项 | 命令/方式 | 预期 |
|--------|----------|------|
| 后端进程 | `curl 127.0.0.1:8081/common/login -X POST -H 'Content-Type: application/json' -d '{}'` | 返回JSON（账号密码错误） |
| nginx反代 | `curl -X POST http://127.0.0.1/api/common/login -H 'Content-Type: application/json' -d '{}'` | 同上 |
| 前端页面 | 浏览器 `http://服务器IP` | 登录页正常显示 |
| 登录 | ROOT/ROOT | 进入管理端 |
| 头像 | 个人中心上传图片 | 成功且显示 |
| 定时任务 | 等次日0点后查 `sys_log_root_event` | 有定时任务事件记录 |

> 云服务器还需在**安全组**放行 80 端口（TCP），其余端口一律不开。

## 九、日常运维

```bash
# 看后端日志
tail -f /opt/njuptphysim/backend.log          # nohup方式
journalctl -u njuptphysim -f                  # systemd方式

# 重启后端
kill 后端进程后重新 nohup 启动；或 sudo systemctl restart njuptphysim

# 更新代码的流程（开发机上执行）
cd NJUPTPhySim-master && mvn package -DskipTests          # 新后端jar
cd ../frontend/njuptpsim && npm run build                 # 新前端dist
# 上传替换 /opt/njuptphysim/*.jar 和 /data/nginx/web/dist/ 后重启对应服务

# 数据库备份
mysqldump -unjupt -p njupt_physim > backup_$(date +%F).sql
```
